ROSARIUM · PUBLICACIÓN EN GITHUB PAGES

1. Descomprime este paquete.
2. Crea un repositorio NUEVO en GitHub, preferiblemente llamado rosarium.
3. Si usas GitHub Free, déjalo PUBLIC.
4. Sube a la RAÍZ del repositorio estos elementos:
   - index.html
   - manifest.webmanifest
   - service-worker.js
   - .nojekyll
   - carpeta icons/
5. Ve a Settings > Pages.
6. En Build and deployment:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
7. Pulsa Save.
8. Espera a que GitHub publique la URL.
9. Abre la URL en Chrome en tu celular e instala ROSARIUM.
